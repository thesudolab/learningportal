How the Flow Works
1. Tool Discovery
The Client first asks the Server for its capabilities. The Server responds with a list of available Tools and Resources.
2. Context Execution
Based on the user request, the Client (AI model) decides which tool to call. It sends a JSON-RPC request with arguments to the MCP Server.
3. Data Injection
The Server processes the request and returns structured data. This data is injected back into the AI's context for a finalized response.
