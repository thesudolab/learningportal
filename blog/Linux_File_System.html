The Linux Filesystem

Unlike Windows, which uses physical drive letters (like C:), Linux utilizes a logical, hierarchical tree structure starting from a single point known as the root (/).

/boot
/home
/proc
/dev
/sbin
/usr
/etc
/mnt

Key Directories

/root
The home directory for the superuser (root).
/etc
Contains system-wide configuration files.
/home
Individual user directories reside here.
/bin
Essential user binaries (executable programs).
/lib
Shared libraries required for binaries.
Pro-tip: Always log in as a regular user for routine tasks. Only use root privileges when strictly necessary to keep your system secure.
