Cyber Kill Chain®

Lockheed Martin

Intelligence Driven Defense® — the model that decomposes an attack into seven discrete, observable, and actionable phases. Each phase offers a window for detection and disruption.

01

Reconnaissance

TA0043

The adversary gathers information about the target organisation, personnel, network architecture, email formats, and more. Includes OSINT, social engineering, network scanning, and passive enumeration.

T1589 T1595 T1592
02

Weaponization

TA0002

The intelligence gathered is turned into deliverable payloads – exploit-laden documents, macro-enabled Office files, custom trojans, or any malicious code tailored to the target environment.

T1204 T1059 T1027
03

Delivery

TA0001

The weaponised payload is transmitted to the target. Common vectors include phishing emails, malicious websites, USB devices, or supply‑chain compromise.

T1566 T1189 T1072
04

Exploitation

TA0002

The vulnerability is triggered and code is executed on the target system. Typical techniques include buffer overflows, script execution, DLL hijacking, or user‑assisted actions.

T1203 T1059 T1068
05

Installation

TA0003 · TA0004

Persistence is established on the compromised host – writing to startup folders, creating scheduled tasks, injecting into system processes, or installing services.

T1547 T1053 T1505
06

Command & Control

TA0011

A C2 channel is established to receive instructions and exfiltrate data. Common protocols: HTTP/S, DNS, ICMP, and tunnelling over Tor or custom encryption.

T1071 T1090 T1572
07

Actions on Objectives

TA0010 · TA0009

The adversary achieves their ultimate goal: data exfiltration, ransomware encryption, destructive wipes, or lateral movement to crown‑jewel systems.

T1048 T1486 T1570

MITRE ATT&CK®

14 tactics · hundreds of techniques

ATT&CK (Adversarial Tactics, Techniques & Common Knowledge) classifies adversary behaviour into tactical objectives and technical procedures. It complements the Kill Chain: the Kill Chain describes attack sequence, while ATT&CK describes attack methods.

TA0043 Reconnaissance
TA0002 Initial Access
TA0003 Persistence
TA0004 Privilege Escalation
TA0005 Defence Evasion
TA0006 Credential Access
TA0007 Discovery
TA0008 Lateral Movement
TA0009 Collection
TA0010 Exfiltration

TA0040 Impact
TA0001 Initial Access (legacy)
TA0000 other tactics

Note: ATT&CK v15 includes 14 tactics; some techniques span multiple tactics.

Unified Defence: From Detection to Disruption

🔍 Kill Chain — Early Blocking

  • Deploy deception (honeypots) and traffic analysis during Reconnaissance
  • Strengthen email gateways and endpoint detection at the Delivery phase
  • Disrupt C2 channels via DNS/HTTP behavioural analytics

🧩 ATT&CK — Precision Hunting

  • Build SIEM use cases around specific techniques (e.g. T1048 Exfiltration)
  • Use ATT&CK Navigator for coverage gap analysis
  • Red/Blue teams simulate and validate using ATT&CK playbooks
# Combining both = a “sequence + means” dual‑layer defence paradigm
