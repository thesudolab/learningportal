Gemini CLI & Agentic Commands Reference

Advanced environmental directives, low-level engine parameters, and shortcut indices for developers.
Context & Execution Prefixes
Core
@<path>
Context Tag. Embeds a target file or folder directly into Gemini's context window (e.g., @src/main.py).
! <command>
Shell Mode. Runs a raw terminal command (e.g., !git diff) and automatically injects stdout back into the chat.
/
Slash Command Prefix. Alerts the interface that the input string is a control mechanism instead of a text prompt.
Workspace & State Control
Slash
/init
Scans the working directory and initializes a localized system instruction layer via a GEMINI.md file.
/memory
Displays or refreshes active environmental constraints and instructions loaded from project directories.
/compress
Condenses active chat logs into a highly summarized token representation to conserve context workspace.
/stats
Outputs performance diagnostics: active models, generation token metrics, and infrastructure latency.
Session Navigation & Agents
Slash
/plan [goal]
Enters Plan Mode. Forces the engine into a read-only architecture state to map logic maps before altering files.
/model <name>
Dynamically switches the active underlying model variant (e.g., trading off speed for deep reasoning).
/save [tag] / /resume [tag]
Creates or loads scoped checkpoints of the conversational state and project tree.
/clear
Flushes the active terminal UI session buffer clean.
Operational Operational Shortcuts
Hotkeys
Ctrl + Y
Enables "YOLO Mode". Disables the interactive prompt step and allows automated tools to run autonomously.
Esc + Esc
The rollback command. Immediately unwinds text mutations and code blocks to the previous system state.
Shift + Tab
Cycles interface operational tracking parameters (Manual Review ↔ Auto-Edit ↔ Read-Only).
Ctrl + X
Splits the active multi-line text buffer outwards into your local native terminal editor (Vim/Nano).
