Claude Code & Agentic Commands Reference

Session controls, subagent orchestration, and low-level reasoning parameters for students running Claude Code from the terminal.

Core

Context & Execution Prefixes

The three symbols that change how your input is interpreted.

@<path>
File Reference Mention. Pulls a file or folder into context and triggers path autocomplete (e.g. @src/main.py).
! <command>
Shell Mode. Runs a raw terminal command directly (e.g. !git status) and adds its output to the conversation without asking Claude to interpret it.
/
Slash Command Prefix. Opens the command menu — filters live as you type, showing built-in commands, skills, and plugin/MCP commands.
Slash

Workspace & State Control

Manage project memory, context load, and installation health.

/init
Scans the project and generates a starter CLAUDE.md file — the persistent instruction layer Claude reads on every session.
/memory
Opens CLAUDE.md for editing, and lets you view or toggle auto-memory entries Claude has saved on its own.
/compact [instructions]
Condenses the active conversation into a summary to free up context, optionally focused with your own instructions.
/context
Renders current context usage as a colored grid — flags memory bloat and heavy tool output before you hit the limit.
/cost
Prints token usage statistics for the current session.
/doctor
Diagnoses your Claude Code installation and settings — the first stop for any environment issue.
Slash

Session Navigation & Agents

Move between models, delegate to subagents, and checkpoint your work.

/agents
Manage subagent configurations — specialized, isolated-context assistants for tasks like code review or debugging.
/model [name]
Switch the active model (sonnet, opus, haiku). Use arrow keys inside the picker to adjust effort level for models that support it.
/plan [description]
Enters Plan Mode directly — a read-only state where Claude maps out an approach before touching any files.
/resume [session]
Resumes a previous conversation by ID or name, or opens the session picker. Alias: /continue.
/rewind
Rewinds the conversation and/or code to a prior checkpoint, or summarizes from a selected message. Alias: /checkpoint.
/clear
Clears conversation history and frees context for a fresh session. Aliases: /reset, /new.
Hotkeys

Operational Shortcuts

Keyboard-only controls for permission modes, history, and reasoning.

Shift+Tab
Cycles permission modes: default → acceptEdits → plan → any enabled custom modes.
Esc Esc
With text in the prompt, clears the draft. With an empty prompt, opens the rewind menu to restore or summarize a previous point in the session.
Ctrl+R
Reverse search through command history, scoped to session, project, or all projects.
Ctrl+O
Toggles the transcript viewer — expands collapsed tool calls and MCP output for full visibility.
Alt+T
Toggles extended thinking for the current session (macOS: Option+T).
Ctrl+B
Backgrounds a running Bash command so you can keep working while it finishes.
Hyperparameters

Low-Level Reasoning & Model Tuning Parameters

For programmatic use and tuning how deeply Claude reasons before it responds.

/effortlow · medium · high · xhigh · max

Sets adaptive reasoning depth. Lower effort is faster and cheaper for routine tasks; higher effort trades tokens for deeper multi-step reasoning on hard problems.

ultrathinkkeyword, one-off

Drop this word anywhere in a prompt to request deeper reasoning on that single turn, without changing your session's persistent effort setting.

--fallback-modelcomma-separated list

Defines a fallback chain Claude Code tries in order if the primary model is overloaded or unavailable, e.g. claude --fallback-model sonnet,haiku.

context windowup to 1M tokens

Long sessions on supported models auto-compact as the window fills — /context shows live usage before that threshold is hit.
